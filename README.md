# Student Merge Sort in Java

This project demonstrates how to sort an array of student records using the **Merge Sort** algorithm in Java. Each student has a name and marks, and the sorting is done in ascending order of marks.

## 🚀 Features
- Uses Merge Sort to sort custom objects (`Student`)
- Demonstrates divide-and-conquer algorithm
- Simple and clean Java implementation

## 📦 How to Run

### Compile
```bash
javac MergeSortApplication.java
